1. Name of my project is KeenKeeper.

2. keenkeep is a frienship oriented web application where users can make call,text,video with their friends and track every activites in a timeline . Its also provides friendship analytics wirh visual statistics.

3. Technologies used :
    - React.js
    - React router
    - Tailwind CSS
    - React Toast
    - React Icons 
    - Recharts

4. Key features :
    - Call, text, video interactions with activity timeline.
    - Frienship analytic page wirh piechart .
    - Toast notification for all interactions .
    - Responsive for mobile, tab and computer .
